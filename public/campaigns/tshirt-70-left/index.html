Anleitung zum Exportieren

  1. Öffne eine der HTML-Dateien unten in einem neuen Tab
  2. Öffne die Developer Tools (Cmd+Option+I auf Mac / F12 auf Windows)
  3. Gehe zu Cmd+Shift+P → "Capture full size screenshot"
  4. Oder nutze ein Tool wie GoFullPage (Chrome Extension)
  5. Die Grafik wird automatisch in der richtigen Größe exportiert
Pro-Tipp: Stelle sicher, dass der Browser-Zoom auf 100% steht und starte den Dev Server mit npm run dev, damit die Bilder laden.
